# Fitswap — Blueprint de Distribuição e Marketing
> Baseado em análise de 100+ apps gerando milhões em MRR

---

## O Diagnóstico Central

> *"Os apps que estão dominando não têm necessariamente o melhor produto. Eles ganham pelo marketing."*

Você está construindo um produto excelente. O problema: **produto sem distribuição é invisível**. Mudar o mindset de "criador de produto" para "operador de distribuição" é o maior alavancador de crescimento disponível agora.

---

## As 4 Fases do Sistema

### Fase 1 — Pesquisa de Mercado (ANTES de qualquer conteúdo)

**Regra de ouro:** nunca pague um criador, nunca poste um vídeo, nunca contrate influencer sem antes entender o que já funciona no nicho.

#### Ferramentas para o Fitswap

| Ferramenta | O que fazer |
|---|---|
| **Sensor Tower** | Buscar apps de meal planning, nutrição, receitas. Só aprender com apps que faturam >$50k/mês |
| **TikTok orgânico** | Pesquisar: "meal prep", "plano alimentar semanal", "o que eu como", "receitas saudáveis", "lista de compras" |
| **TikTok Ads Library** | Ver os top ads de apps de fitness/nutrição nos últimos 180 dias |
| **Facebook Ads Library** | Buscar concorrentes (MyFitnessPal, Yazio, Lifesum) — quantidade de ads ativos = sinal positivo |

#### Planilha de pesquisa (montar isso antes de qualquer post)

```
URL do vídeo | Plataforma | Likes | Views | Tema/Hook | O que funciona | Posso replicar?
```

**Competidores diretos para estudar:**
- Yazio (meal planning)
- Lifesum (dieta personalizada)
- MyFitnessPal (tracking)
- Mealime (receitas semanais)
- Whisk (lista de compras)

#### Palavras-chave para pesquisar organicamente

- TikTok BR: "plano alimentar", "meal prep semana", "o que eu comi hoje", "lista de compras saudável", "receita fitness", "scanner de alimentos"
- TikTok EN: "weekly meal plan", "what I eat in a day", "meal planning app", "grocery list app", "AI food scanner"

### Fase 2 — O App como Funil (otimizar antes de gastar em ads)

> *"A razão pela qual você não está ganhando é que esses apps ganham mais por usuário. Quanto mais você ganha por usuário, mais pode gastar em ads."*

Esse é o ponto mais crítico. Sem funil convertendo bem, qualquer investimento em marketing é dinheiro jogado fora.

#### O funil do Fitswap (cada etapa precisa estar otimizada)

```
Conteúdo / Ad
     ↓
App Store Listing (screenshots, título, subtítulo, descrição)
     ↓
Download
     ↓
Onboarding (friction positivo — coletar gosto, objetivo, preferências)
     ↓
Paywall (A/B test contínuo)
     ↓
Trial → Assinante → LTV
```

#### Checklist de otimização do funil Fitswap

**App Store Listing:**
- [ ] Screenshots mostram *resultado* (plano pronto, lista gerada, refeição bonita), não features
- [ ] Subtítulo tem keyword forte ("Plano alimentar com IA")
- [ ] Preview video de 15-30s mostrando o fluxo completo

**Onboarding:**
- [ ] Perguntas de sabor/preferência logo no início (o Fitswap já faz isso — reforçar valor disso)
- [ ] Mostrar o plano gerado ANTES de pedir pagamento (aha moment)
- [ ] Friction positivo: cada pergunta deve fazer o usuário sentir que o resultado será personalizado

**Paywall:**
- [ ] Testar diferentes posições (antes vs. depois do aha moment)
- [ ] Testar preço anual vs. mensal vs. lifetime
- [ ] Mostrar o valor entregue antes do preço

**Métrica principal:** LTV por install (usar RevenueCat para medir)

### Fase 3 — Escalar com Criadores

#### Hierarquia de criadores (do mais barato ao mais caro)

1. **Você mesmo (founder)** — mais autêntico, zero custo, começar aqui
2. **Conteúdo faceless** — vídeo de tela do app, receitas sendo geradas, plano aparecendo
3. **Micro criadores** (10k-100k seguidores) — nicho de alimentação/fitness, pagar por CPM
4. **UGC Creators** — criadores pagos para fazer conteúdo que você possui
5. **Influencers** — só quando tiver funil validado e LTV confirmado

#### Como estruturar deals sem perder dinheiro

- Pagar por **CPM** (custo por mil visualizações) — você só paga por resultado
- Exigir **Spark Ads code** — você possui o conteúdo e pode rodar como paid ad
- Garantia de views mínima para influencers maiores
- **Nunca pagar flat rate sem garantia de views**

#### Tipos de conteúdo que funcionam para o nicho alimentar

| Formato | Exemplo para o Fitswap | Esforço |
|---|---|---|
| "O que eu comi essa semana" | Mostrar plano gerado pelo app como resultado | Baixo |
| Story time | "Parei de gastar $300/mês no mercado fazendo isso" | Baixo |
| Antes/depois | Geladeira vazia → lista de compras gerada → geladeira organizada | Médio |
| Tutorial rápido | "3 segundos para ter sua lista de compras da semana" | Baixo |
| Listicle | "3 apps que mudaram como eu me alimento" (Fitswap como #1) | Baixo |
| UGC real | Usuário real mostrando o plano gerado para a família | Médio |
| Scanner viral | Escanear alimento aleatório e mostrar resultado nutricional | Baixo |

### Fase 4 — Paid Ads (só depois das fases 1-3)

> *"Paid ads são a forma mais poderosa de crescer. Mas você precisa do funil otimizado primeiro."*

#### Quando começar paid ads

- ✅ Tem pelo menos 20 peças de conteúdo postadas organicamente
- ✅ Sabe qual formato/hook converte mais downloads
- ✅ Tem LTV por install calculado no RevenueCat
- ✅ Onboarding e paywall já foram testados

#### Como rodar paid ads para o Fitswap

1. **Subir os melhores vídeos orgânicos** como ads (não criar conteúdo novo para ads no início)
2. **Otimizar para money events**, não clicks ou installs:
   - Trial start
   - Assinatura confirmada
3. **Métricas que importam:**
   - CAC (Custo de Aquisição de Cliente) — quanto paga por assinante
   - LTV (Lifetime Value) — quanto cada assinante gera no total
   - **Regra:** CAC < LTV = crescimento sustentável
4. **Testar criativos em massa** — mínimo 5-10 variações de hook por campanha

## A Regra das CTAs Discretas

> *"Seus vídeos não podem parecer uma venda. Não venda as features. Venda o resultado."*

#### Errado vs. Certo

| ❌ Não fazer | ✅ Fazer |
|---|---|
| "O Fitswap tem scanner de IA e gera lista de compras" | Mostrar pessoa chegando do mercado sem estresse |
| "Baixe o Fitswap no link da bio" | "Esse app mudou como eu faço compras" (produto aparece na tela) |
| Explicar como o app funciona | Mostrar o resultado final (plano pronto, geladeira organizada) |
| "Nossa tecnologia de IA..." | "Nunca mais jogo comida fora desde que comecei a usar isso" |

#### Fórmula de CTA discreta

```
[Situação relatable] + [Resultado desejado] + [Produto aparece naturalmente na tela]
```

Exemplo: "Sexta-feira eu não sabia o que cozinhar essa semana... [pausa] ...segunda-feira eu já tinha tudo comprado e os almoços feitos." — câmera mostra a tela do app rapidamente.

## Maximizar Cada Peça de Conteúdo

**Uma gravação → múltiplas plataformas:**

```
TikTok → Instagram Reels → YouTube Shorts → Facebook Reels
```

**Engajamento ativo:**
- Responder comentários com vídeo (TikTok permite "reply to comment" com vídeo)
- Se um vídeo viraliza, responder ao comentário mais votado com novo vídeo
- Isso multiplica o alcance sem criar conteúdo do zero

## Resumo Mental

> O sistema completo em uma frase: **pesquise o que já funciona no nicho → otimize o funil para maximizar LTV → crie conteúdo baseado no que funciona → escale com criadores → use os melhores orgânicos como paid ads → repita.**

A diferença entre os apps que faturam milhões e os que ficam estagnados não é o produto — é que os grandes **tratam distribuição como produto**. Cada semana sem postar é uma semana sem aprender o que converte.
